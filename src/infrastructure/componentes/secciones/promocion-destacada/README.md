# Promoción destacada

Sección de Captación; cuenta para el límite.

Props exportadas: `PromocionDestacadaProps`. Todas son opcionales: `id`, `titulo`, `descripcion`, `etiqueta`, `imagen` y `accion: {texto, href}`. Sin imagen o acción no reserva esos elementos. No incluye temporizadores, animaciones ni peticiones. La demo dirige la acción a Contacto.

Para copiar, excluir `ejemplo.ts` y `definicion.ts`; incluir `base/MarcoSeccion`, `base/Contenedor`, `base/TituloSeccion`, `base/ImagenContenido`, `base/Boton`, `Boton/estilos.ts`. Requiere React, Next Image y Tailwind 3 con tokens `brand`, `seccion`, `fontFamily.sans`, `outlineWidth.foco`, `spacing.demo-ancla` y variante `fine-pointer`.
