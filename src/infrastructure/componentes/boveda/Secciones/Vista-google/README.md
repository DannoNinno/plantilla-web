# Vista previa en Google

Maqueta disponible en la administración de Captación. No cuenta para las diez secciones y no se ensambla en el sitio visitante.

Props exportadas: `VistaGoogleProps`. Todas son obligatorias: `etiqueta`, `url`, `titulo`, `descripcion`, `nota`. URL se muestra solo como texto; no se visita ni consulta Google. No promete posiciones reales ni modifica metadatos del sitio. El panel permite editar sus textos en memoria.

Para copiar, excluir `ejemplo.ts` y `definicion.ts`. Requiere React, `lucide-react` (ya existente en el proyecto), Tailwind 3 con tokens `brand` y `fontFamily.sans`. No necesita otras secciones ni datos del negocio.
